# Claude Design Brief

Use this prompt in Claude Design with the attached `codexpets-top10` pet packs/spritesheets.

```text
You are the founding product designer and launch content strategist for Move Pet.

Goal: update the visual design system for Move Pet using the attached CodexPets references as inspiration only. Also decide the best 20-day social media/content plan yourself based on the product, audience, and launch needs. Do not copy protected characters, celebrity likenesses, or exact pet designs. Extract reusable design ideas: expressive idle/disturbed/happy states, compact silhouettes, collectible cuteness, pixel/chibi readability, and movement-friendly animation cues.

Product:
- Move Pet is a lightweight desktop companion for gamers, coders, workers, and social scrollers who sit too long.
- After long inactivity, a tiny pet appears and looks disturbed.
- When the user moves, it gets happy, floats with them, disappears after 3 seconds, and shows estimated calories burned.
- Optional strict mode can lock keyboard/mouse until a movement target is met.
- Motion detection is local and lightweight; privacy-first webcam processing means no frames leave the device.
- Core wedge: cute emotional accountability + local movement verification, not another dismissible break reminder.

Audience:
- Primary: gamers, indie hackers, coders, students, creators, and deep-work users who ignore normal reminders.
- Emotional job: "I need a tiny friend that makes movement feel harder to ignore and less boring."
- Voice: cute, direct, slightly mischievous, never preachy.

Reference pets attached:
1. Pixel Coder - friendly coder archetype for builder/gamer affinity.
2. Hoop Duck - sporty motion cue and playful fitness bridge.
3. Dad Coder - work-break props and expressive review poses.
4. Happy Pup - readable cute companion baseline.
5. Tiny Dino - compact silhouette and expressive workday poses.
6. Poddy - tech/utility mascot credibility.
7. Round Cola Hatch - round hatchable body and clear behavior states.
8. Scottish Fold Cat - soft movement and failure animation reference.
9. Munchkin Short Leg Cat - funny scurrying movement reference.
10. Ruby Lynx - fantasy collectible direction and accent-color personality.

Design-system work:
- Create an original Move Pet mascot direction, not a clone of any reference.
- Define brand foundation: positioning, promise, personality, voice, audience, emotional arc.
- Define design tokens: colors, typography, spacing, radii, shadow, motion durations, icon style.
- Define mascot state system: idle, neglected/disturbed, encouraging, moving, happy, floating, victory, sleeping, strict-mode warning, privacy-camera active.
- Define UI components: desktop overlay widget, movement prompt, strict-mode lock screen, victory toast, privacy badge, pet picker, settings controls, waitlist form, landing-page CTA, FAQ, social-proof placeholders.
- Define asset rules: silhouette, line weight, shading, spritesheet guidance, animation loops, do/don't examples, accessibility rules.
- Keep UI practical for a desktop companion: compact, scan-friendly, not a marketing-only hero page.

Landing-page update:
- First viewport must show the actual product idea immediately: pet appears after inactivity, user moves, pet celebrates, local-only privacy proof.
- Include headline, subheadline, waitlist CTA, how it works, strict mode, mascot states, privacy, FAQ, final CTA.
- Copy should be short, specific, and shippable.

20-day content plan:
- Decide the strongest content strategy yourself.
- Choose the right platforms, formats, themes, cadence, hooks, scripts, CTAs, and production approach.
- Keep it realistic for a solo founder using lightweight assets and short-form production.

Output exactly:
1. Brand Foundation
2. Design Tokens
3. Mascot + Asset System
4. Desktop UI Component System
5. Landing Page Spec
6. 20-Day Social Content Plan
7. Production Checklist
8. Immediate Design Tasks For The Developer

Be concrete. Provide names, colors, UI copy, component specs, animation timing, examples, and content scripts. Avoid abstract strategy filler.
```
