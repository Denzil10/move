## 2026-09-28 - Add ARIA Labels to Toast Close Buttons\n**Learning:** The application uses several toast notifications (AchievementToast, GoalReachedToast, LevelUpToast, VictoryToast) that have icon-only '×' close buttons. These lack `aria-label` attributes, making them inaccessible to screen reader users who won't know what the button does.\n**Action:** Add `aria-label="Close"` to all icon-only close buttons in toast components to improve accessibility.
