## 2024-05-18 - App-specific pattern: Missing ARIA Labels on Emojis
**Learning:** The application heavily relies on single-character emojis (like ×, 💬) and inline SVGs for interactive icon-only buttons (such as in modals, toasts, and pet interactions). This pattern inherently lacks accessible names for screen readers unless explicitly provided, leading to widespread WCAG 2.5.3 violations.
**Action:** Always verify that newly created components, particularly toasts, modals, or floating bubbles featuring emoji or SVG close/chat buttons, include an explicit `aria-label` attribute (e.g., `aria-label="Close"`) prior to creating a PR to prevent systemic accessibility gaps. Conversely, avoid overriding meaningful text with `aria-label`s on buttons that already contain visible, descriptive text (e.g. `DailyRecap.tsx` "Let's start today! 🚀").
