## 2024-08-24 - Missing ARIA Labels on Icon-only Close Buttons\n**Learning:** The application heavily uses icon-only close buttons (× or &times;) in modals and toasts without proper ARIA labels, creating a significant accessibility barrier for screen readers.\n**Action:** Added `aria-label="Close"` to all identified instances in the `apps/desktop/src/components/` directory to ensure consistent keyboard accessibility and screen reader support.
