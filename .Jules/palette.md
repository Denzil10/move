## 2023-10-27 - Added Missing ARIA Labels to Action Buttons
**Learning:** The Move Pet desktop app relies heavily on icon-only buttons for interactions (e.g., `×` for closing modals, `💬` for chats). I've discovered multiple instances across different toast/modal components where these interactive, icon-only components lack proper `aria-label`s, which causes an accessibility gap for screen readers.
**Action:** Added `aria-label` attributes to missing icon-only buttons (`×` and `💬`) across `apps/desktop/src/components/*` to ensure accessibility and consistent keyboard navigation for visual/screen-reader users. Going forward, standardizing interactive components early (or using a custom Icon component wrapper with enforced `aria-label` props) could avoid these recurring gaps.
