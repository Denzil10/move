## 2024-06-07 - Add ARIA Labels to Icon-Only Close Buttons
**Learning:** The Move Pet desktop app relies heavily on icon-only buttons (e.g., '×' and '💬') for actions like closing toasts or chatting. Without explicit aria-labels, screen readers lack context for these interactions.
**Action:** Ensure all interactive components using icon-only representations include descriptive aria-label attributes for better accessibility and screen reader support.
