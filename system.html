Move Pet — System Snapshot · 2026-05-10

Regular movement, made hard to ignore.

A tiny desktop pet appears when you've been still too long, gives one movement prompt, scores motion locally, celebrates, and gets out of the way. Tauri + React, privacy-first, no cloud required.

Architecture & Logic

One compact desktop loop: inactivity detection → pet gets disturbed → movement prompt → local motion scoring → reward. All computation stays on-device.

1

Inactivity Detection

useInactivity tracks idle time. When threshold is exceeded, pet state transitions to disturbed. Configurable timeout (default 30 min). Respects quiet hours and productivity mode.

2

Pet Overlay

Transparent always-on-top Tauri window. Renders CSS-blob dragon (emerald_dragon) or animated spritesheet pet (tiny_dino — 8×9 grid, 192×208px cells). State-mapped frame animation via SpriteAnimation.tsx.

spritesheet live 8 pet states
3

Motion Detection

Tauri device motion API via useMotionDetection hook. Scores movement with configurable threshold. macOS permission grant required — not yet verified on device. Frames never leave the app.

needs device test
4

Reward Loop

Sufficient motion → pet becomes happy / floating. Achievements unlock, XP + coins awarded, streak extended, quests progress. Quest system, daily recap, and share card all wired in.

Pet States

idle · disturbed · happy · floating · thinking · sleeping · chatting · training

Each maps to a spritesheet row (row 0–7) and CSS animation class. Sound cues trigger on state change.

Species System

15+ collectable species in collection.ts. Spritesheet species carry SpritesheetMeta (src, cols, cellWidth, cellHeight, stateRows). Tiny Dino auto-unlocked at start.

Quest & XP

Daily quests (walk, sleep, shopping, hydration targets). XP = calories burned × multipliers. Level-gated species unlocks, personality unlocks at level 5+.

Autopilot Guard

Known corruption pattern: autopilot inserts empty if (soundEnabled) {`{}`} blocks, leaving function bodies unclosed. Rule: always use if (soundEnabled) playX(); single-line form and verify build passes.
